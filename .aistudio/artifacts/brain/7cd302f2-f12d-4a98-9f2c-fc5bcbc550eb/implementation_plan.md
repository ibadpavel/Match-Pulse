# План доработок: Football-Data.org Live API + iCalendar (.ics)

Интеграция официального REST API Football-Data.org с предоставленным API-токеном для получения матчей на сегодня и live-счёта в реальном времени (автообновление раз в 60 секунд), а также подключение надёжного парсера iCalendar (.ics) для загрузки полного расписания предстоящих туров Лиги Чемпионов и Лиги Европы.

---

## User Review & Critical Decisions

> [!IMPORTANT]
> На основе ваших ответов зафиксированы следующие архитектурные решения:
> - **API-токен**: Токен `96d158049e4141a0bc84b3a107007158` встроен по умолчанию и может быть изменён или проверен в меню «Настройки».
> - **Live-обновление**: В период проведения активных матчей (`IN_PLAY` / `PAUSED`) счёт и статус обновляются автоматически каждые 60 секунд без зависания интерфейса.
> - **Гибридная модель данных**: 
>   1. **Football-Data.org API**: загрузка сегодняшних игр, актуального live-счёта и авторов голов/статуса матча.
>   2. **iCalendar (.ics) / турнирный календарь**: расписание всех предстоящих туров ЛЧ и ЛЕ с временем по МСК и стадионами.
> - **Вёрстка под Samsung Galaxy S25**: сохранение двухстрочного блока фильтров (кнопка «Результаты» строго на отдельной строке), компактные пилюли турниров и адаптивные карточки.

## 1. Overview & Core Concept

- **Что даёт обновление**:
  - Полное избавление от любых синтетических матчей — 100% достоверная информация прямо из европейского футбольного API.
  - Появление настоящего **Live-режима**: если матч идёт прямо сейчас, карточка подсвечивается неоновым индикатором, показывает текущую минуту/тайм и счёт, обновляясь раз в 60 секунд.
  - Синхронизация календаря: парсинг календарей турниров гарантирует, что пользователь видит реальную сетку игр на месяцы вперёд.

## 3. Key Product Decisions & Trade-Offs

- **Решение 1: Запросы к Football-Data.org через Retrofit с авторизацией по токену**
  - *Реализация*: OkHttp Interceptor автоматически добавляет заголовок `X-Auth-Token: 96d158049e4141a0bc84b3a107007158`.
  - *Эндпоинты*:
    - `GET v4/matches?dateFrom={today}&dateTo={today}` — матчи сегодняшнего дня всех еврокубков с live-счетом.
    - `GET v4/competitions/CL/matches?status=LIVE,IN_PLAY` — быстрый опрос текущих матчей ЛЧ.
    - `GET v4/competitions/EL/matches?status=LIVE,IN_PLAY` — быстрый опрос текущих матчей ЛЕ.
- **Решение 2: Встроенный парсер iCalendar (.ics)**
  - *Реализация*: Легковесный парсер потока строк без тяжелых внешних библиотек (считывает блоки `BEGIN:VEVENT`, поля `DTSTART`, `SUMMARY`, `LOCATION`, `DESCRIPTION`).
  - *Преимущество*: Мгновенно формирует расписание будущих недель без траты драгоценных лимитов API.
- **Решение 3: Умный фоновый опрос (Smart Polling)**
  - *Реализация*: Если на сегодня нет матчей со статусом `IN_PLAY` / `PAUSED`, опрос прекращается. Если хотя бы один матч активен — запускается корутина с задержкой 60 секунд.

## 5. Порядок реализации (после утверждения)

1. **Сетевой клиент Football-Data.org**:
   - DTO модели Moshi (`MatchResponse`, `ScoreDto`, `TeamDto`).
   - Retrofit-интерфейс с поддержкой заголовка `X-Auth-Token`.
   - Внедрение токена по умолчанию с сохранением в `SharedPreferences` / настройках.
2. **Парсер календаря iCalendar (.ics)**:
   - Модуль `IcsScheduleParser` для чтения стандартных потоков `.ics` и конвертации событий в `MatchEntity`.
3. **Обновление репозитория и ViewModel**:
   - Метод `syncTodayLive()` — вызов Football-Data API для матчей дня и live-счёта.
   - Метод `syncSeasonCalendar()` — чтение турнирной сетки.
   - Автоматический цикл опроса раз в 60 секунд во время активных игр.
4. **Интерфейс настроек**:
   - Добавление в `SettingsDialog` поля просмотра и редактирования API-токена Football-Data с кнопкой проверки соединения («Проверить токен»).
5. **Сборка и валидация**:
   - Запуск `compile_applet`, модульные тесты и генерация готового APK `UEFA-Match-Pulse.apk`.
